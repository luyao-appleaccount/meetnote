📖 会记 MeetNote · 使用说明

本地运行的智能会议纪要:录音转写、说话人分离、纪要提取、行动项追踪全部在本机完成,数据不出你的电脑。由 faster-whisper + sherpa-onnx + Silero VAD 驱动。

一、三种方式生成纪要

实时录制:「开始新会议」→ 填标题、选说话人数(已知人数时指定,分离更准) → 会中实时出字,可悬停句子标记重点/待办 → 「结束会议」自动保存录音、分离说话人、生成纪要。
导入录音:把已有的录音/视频文件(m4a/mp3/wav/mp4…)导入,自动完成转写与说话人分离,几分钟的音频约几十秒处理完。
高质量重转:详情页的「全文转写」支持用 medium / large-v3 模型重新转写(首次会下载模型,几分钟后切换版本对比)。

二、纪要是怎么生成的

会议结束后,系统自动执行:保存录音 → 说话人分离(声纹聚类)→ 纪要提取。纪要提取默认使用本地规则引擎:按信息量挑出关键要点、识别「决定/拍板/通过」等决策句、识别「我来负责/周五之前」等行动项(自动关联说话人与期限)。若配置了 LLM 环境变量,则改用大模型生成更高质量的纪要。

开启 LLM 增强(可选):启动服务前设置环境变量 MEETNOTE_LLM_BASE_URL / MEETNOTE_LLM_API_KEY / MEETNOTE_LLM_MODEL(任意 OpenAI 兼容接口),重启服务即生效。

三、数据与隐私

数据库(SQLite)与录音文件保存在程序目录 data/ 下,可随时备份或删除。
导出的 Markdown 包含概览、要点、决策、行动项与全文转写;原始音频可从详情页下载。
删除会议会同时删除其转写、行动项与关联数据,不可恢复。
